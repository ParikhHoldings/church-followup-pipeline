# Church Follow-Up Pipeline

Landing page + lead magnet funnel for HappyWP's church follow-up blueprint.

## Live goal
- Free blueprint capture page
- HappyWP implementation service funnel
- Beehiiv subscription capture via `/api/subscribe`

## Stack
- Next.js 14
- Tailwind CSS
- Beehiiv API

## Local dev
```bash
npm install
npm run dev
```

## Required env vars
- `BEEHIIV_API_KEY`
- `BEEHIIV_PUB_ID`
